1. Pengertian Bootstrap
Bootstrap adalah framework yang membantu kita membuat tampilan website menjadi lebih rapi dan responsif. Bootstrap sudah menyediakan berbagai class untuk mengatur tombol, form, warna, jarak, dan tata letak, jadi kita tidak perlu menulis semua CSS dari awal.
2. Cara memasang Bootstrap
Bootstrap bisa digunakan dengan beberapa cara, yaitu melalui CDN, mengunduh file Bootstrap, atau memasangnya menggunakan NPM. Untuk tugas ini, saya menggunakan CDN karena lebih mudah dan tidak perlu mengunduh file Bootstrap terlebih dahulu.
3. Grid dan breakpoint
Grid digunakan untuk mengatur posisi dan lebar elemen pada halaman website menggunakan baris dan kolom. Sementara itu, breakpoint digunakan untuk menyesuaikan tampilan berdasarkan ukuran layar, misalnya layar HP, tablet, dan laptop.
4. Class Bootstrap dan kegunaannya
Class	Kegunaan
container	Membatasi dan merapikan area konten.
row	Membuat baris untuk menyusun kolom.
btn btn-primary	Membuat tombol berwarna biru.
form-control	Mengatur tampilan kolom input.
text-center	Membuat teks berada di tengah.
shadow	Memberikan bayangan pada elemen.
5. Gambar responsif
Agar gambar menyesuaikan ukuran layar, kita bisa menggunakan class img-fluid pada tag <escape><img></escape>. Class tersebut membuat lebar gambar mengikuti ukuran wadahnya dan menjaga proporsi gambar agar tidak berubah.
